# 桌宠（Desktop Pet）

一个用 C# 写的 Windows 桌面宠物。

## 给「新会话 / 新电脑」的入口

1. 先读 [`AI_CONTEXT.md`](AI_CONTEXT.md) —— 项目记忆、环境、当前进度、下一步。
2. 再读 [`docs/技术路线.md`](docs/技术路线.md) —— 架构、关键技术点、里程碑。
3. 需要翻旧账就读 [`docs/决策记录.md`](docs/决策记录.md) —— 为什么这么选。

## 当前状态

路线规划完成，尚未开始编码（M0 之前）。详见 `AI_CONTEXT.md` 第 6 节。

## 协作约定

- 本项目以「边做边学」方式推进，默认不直接给出完整代码。
- 一次只推进一个里程碑。
- 每次会话结束更新 `AI_CONTEXT.md`。

## 环境提示

- 项目根 `G:\桌宠` 位于 **exFAT** 分区：不支持硬链接/符号链接，构建会比 NTFS 慢，建议把 `bin/obj` 重定向到 NTFS 盘。
- 路径含中文，脚本中务必加引号。
